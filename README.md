# Mini-Project

##  Deskripsi Singkat
Ini adalah proyek mini sederhana yang dibuat untuk belajar pengembangan web dengan **Streamlit**. Aplikasi ini bertujuan memperlihatkan antarmuka interaktif untuk input data, memuat model Machine Learning, dan menampilkan prediksi secara visual.

---

##  Fitur
- Halaman **Home** dengan informasi singkat tentang proyek.
- Halaman **Machine Learning** untuk memasukkan data dan menerima output model.
- Layout responsif dengan sidebar navigasi.
- Kemudahan dalam set-up dan penggunaan (One-command setup).

---

##  Teknologi yang Digunakan
| Teknologi | Deskripsi |
|-----------|-----------|
| Python    | Bahasa pemrograman inti |
| Streamlit | Framework untuk UI web interaktif |
| scikit-learn | Library untuk pemrosesan model ML |
| joblib    | Untuk load/save model |
| pandas & NumPy | Library untuk manipulasi data |
| Git & GitHub | Version control dan hosting repo |
